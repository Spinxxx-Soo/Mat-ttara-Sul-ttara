# 프로젝트 기술 명세 및 리소스 가이드

본 문서는 프로젝트의 배포, 데이터베이스 구성, 외부 API 계정 및 데이터 구조(ERD) 등을 관리하기 위한 핵심 기술 정보를 포함하고 있습니다.

## 1. 배포 시 특이사항 및 가이드

### 개발 및 실행 환경
- **Frontend**: Vite + React (TypeScript)
  - 실행: `cd FE && npm install && npm run dev`
  - 포트: 기본 `5173`
- **Backend**: Spring Boot (Java 17)
  - 실행: `cd BE && ./gradlew bootRun` (Docker Compose 우선 실행 필요)
  - 포트: 기본 `8080`
- **AI/LLM**: FastAPI (Python 3) + LangGraph
  - 실행: `cd AI && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && python3 main.py`
  - 포트: 기본 `5000` (BE의 `AI_BASE_URL` 설정 확인)

### 인프라 구성 (Docker Compose)
- **위치**: `BE/docker-compose.yml`
- **관리 명령어**:
  - 실행: `docker-compose up -d`
  - 중지: `docker-compose down`
- **주의사항**:
  - AWS VPC 환경 배포 시 서브넷 대역(`10.50.0.0/16`) 충돌 여부를 반드시 확인하십시오.
  - Elasticsearch 구동 시 `analysis-nori` 플러그인이 자동으로 설치되도록 설정되어 있습니다.

## 2. 데이터베이스(DB) 접속 정보

| 서비스 | 엔진 | 기본 포트 | 데이터베이스 명 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **RDBMS** | MySQL 8.0 | `3306` | `matsul` | 실 서비스 데이터 저장 (Soft Delete 적용) |
| **Cache/PubSub** | Redis Stack | `6379` | `0` (AI Checkpoint), `1` (BE Bridge) | AI 대화 상태 및 백엔드 연동용 |
| **Search Engine** | Elasticsearch 8.12.0 | `9200` | - | Nori 형태소 분석기 필수 |

> [!IMPORTANT]
> DB 비밀번호 등 민감 정보는 각 서비스의 `.env` 파일에서 관리하며, `docker-compose.yml` 실행 전 반드시 환경 변수가 설정되어야 합니다.

## 3. 주요 계정 및 프로퍼티 파일 목록

### 주요 설정 파일 위치
- **Backend**:
  - `BE/src/main/resources/application.yml`: 서버 핵심 로직 및 외부 연동 설정
  - `BE/.env`: DB 접속 정보, JWT Secret, AWS/Social Login Key
- **Frontend**:
  - `FE/.env`: API Base URL, Kakao/Naver Map JS Key, OAuth Client ID
- **AI**:
  - `AI/.env`: OpenAI/GMS API Key, DB 호스트, Redis URL

### 외부 API 리소스 명세
- **Google Cloud**: OAuth2 로그인, GMS(LLM) 연동
- **Naver Developers**: 지도 API, 지역 검색 API, OAuth2 로그인
- **Kakao Developers**: 지도 JS SDK, 로컬 검색 API, OAuth2 로그인
- **AWS**: S3 (이미지 스토리지) - 버킷: `matsul-image-storage-...`
- **OpenAI / GMS**: GPT-4-mini 모델 연동 (GMS Proxy 사용)

## 4. ERD (Entity Relationship Diagram)

프로젝트의 주요 엔티티 관계 요약입니다. (상세 내역: `AI/erd.dbml` 참조)

### 핵심 테이블 구조
1. **사용자 관련**: `users`, `user_auth`, `user_preference`
   - 구글/네이버 소셜 로그인 연동 및 사용자 취향 데이터 관리
2. **장소 및 리뷰**: `places`, `place_meta`, `reviews`, `crwl_reviews`
   - 네이버/카카오 API 기반 장소 정보와 AI 요약 리뷰, 크롤링 데이터 저장
3. **플랜 및 대화**: `plans`, `plan_details`, `chat_sessions`, `chat_messages`
   - 사용자 생성 플랜 정보와 AI 챗봇과의 대화 이력 관리
4. **AI 메모리**: `user_memory`, `place_memory_vector`
   - 사용자별 페르소나와 장소별 24차원 특징 벡터 데이터

## 5. 관리 및 수복 가이드
- **캐시 초기화**: Redis 데이터 만료 또는 충돌 시 `redis-cli FLUSHALL` 수행 (주의 필요)
- **인덱스 재설정**: Elasticsearch 매핑 변경 시 스키마 재정의 및 데이터 재색인 필요
- **환경 변수 동기화**: `FE`, `BE`, `AI` 간 API 키 및 URL 설정이 일치하는지 항상 점검하십시오.
