### 3.1.1 환경 변수 목록 (Environment Variables)

이 목록은 프로젝트 루트의 `.env` 파일 또는 배포 환경(Docker Compose, CI/CD)에서 주입되는 핵심 설정값입니다.

| 영역 | 키 (Key) | 필수 | 보안 등급 | 기본값 / 설명 |
| :--- | :--- | :---: | :---: | :--- |
| **DB** | `DB_HOST` | 필수 | 내부 | MySQL 호스트 (Docker 서비스명: `mysql`) |
| **DB** | `DB_USERNAME` | 필수 | 비밀 | 애플리케이션 DB 사용자 (예: `root`) |
| **DB** | `DB_PASSWORD` | 필수 | 비밀 | DB 비밀번호 (`dk04020402A!`) |
| **Redis** | `REDIS_HOST` | 필수 | 내부 | Redis 호스트 (Docker 서비스명: `redis`) |
| **ES** | `ES_HOST` | 필수 | 내부 | Elasticsearch 호스트 (Docker 서비스명: `elasticsearch`) |
| **OAuth** | `GOOGLE_ID` | 필수 | 내부 | 구글 OAuth 클라이언트 ID |
| **OAuth** | `GOOGLE_SECRET` | 필수 | 비밀 | 구글 OAuth 클라이언트 보안 비밀번호 |
| **OAuth** | `NAVER_ID` | 필수 | 내부 | 네이버 OAuth 클라이언트 ID |
| **OAuth** | `NAVER_SECRET` | 필수 | 비밀 | 네이버 OAuth 클라이언트 보안 비밀번호 |
| **Map** | `KAKAO_API_KEY` | 필수 | 비밀 | 카카오 REST API 키 (장소 검색용) |
| **AWS** | `AWS_KEY` | 필수 | 비밀 | S3 접근용 Access Key |
| **AWS** | `AWS_SECRET` | 필수 | 비밀 | S3 접근용 Secret Key |
| **Security** | `JWT_SECRET` | 필수 | 비밀 | JWT 서명용 비밀키 (최소 32바이트 권장) |
| **AI** | `AI_BASE_URL` | 필수 | 내부 | AI 서버 주소 (`http://ai:5000`) |
| **Front** | `VITE_API_BASE_URL` | 필수 | 내부 | API 상대 경로 (예: `/api`) |
| **Front** | `VITE_WS_URL` | 필수 | 내부 | WebSocket 연결 주소 (예: `wss://j14b205.p.ssafy.io/ws`) |

---

#### 💡 보안 등급 안내
* **공개(Public):** 외부 공개해도 무해한 설정값
* **내부(Internal):** 시스템 구조 및 도메인 정보 (외부 노출 비권장)
* **비밀(Secret):** 키, 토큰, 비밀번호 (유출 시 보안 사고 위험, **절대 Git 금지**)

#### 📝 운영 참고 사항
1. **Docker Network:** 모든 호스트명(`DB_HOST` 등)은 `docker-compose.yml`에 정의된 서비스 이름과 일치해야 컨테이너 간 통신이 가능합니다.
2. **Redirect URI:** 구글/네이버 콘솔에 등록된 Redirect URI와 백엔드 `application.yml`에 설정된 주소가 100% 일치해야 OAuth 인증이 성공합니다.
3. **.env 관리:** 운영 서버에서는 `~/S14P21B205/BE/.env` 경로에 파일을 생성하여 관리합니다.
