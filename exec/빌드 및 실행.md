## 1.1 OS/하드웨어 권장 사양

1) API 및 인프라 서버 운영 환경 (AWS EC2)

- OS / 플랫폼
    - OS: Ubuntu 22.04.5 LTS (Jammy Jellyfish) (확인된 사양)
    - Kernel: 6.2.0-1018-aws 기반
    - Hosting: Amazon EC2 (t3.xlarge급 권장)
    - Shell: bash 5.1.16
    - Package Manager: apt (snap docker 사용 중)
    
- 하드웨어 (운영 기준)
    - CPU: 4 vCPU 이상 (MySQL, Redis, ES, Spring Boot 동시 가동 고려)
    - RAM: 16GB (Elasticsearch 가동을 위해 최소 8GB 이상 필수)
    - Storage: SSD 50GB 이상
    
- 운영 기준 요약
    - API 및 인프라 서버는 Ubuntu 22.04 LTS + 4 vCPU / 16GB RAM 환경에서 도커 컨테이너 기반으로 통합 운영한다.
    
2) AI 서버 운영 환경
- OS / 런타임
    - OS: Ubuntu 22.04 LTS (또는 동일 사양의 컨테이너)
    - Runtime: Python 3.10+
- 하드웨어
    - CPU: 2 vCPU 이상
    - RAM: 4GB 이상
- 운영 기준 요약
    - AI 서버는 FastAPI 기반으로 구동되며, 백엔드와의 통신을 위해 외부 수신(0.0.0.0) 설정으로 운영한다.

## 1.5 웹서버/WAS 핵심 설정값
1.5.1 웹서버 (Nginx)
- SSL 설정: Certbot(Let's Encrypt) 적용, https 강제 리다이렉트
- Proxy Pass: * /api → http://sulddara-backend:8080/ws → 백엔드 WebSocket 경로 (wss 전환)
- SPA 처리: try_files $uri $uri/ /index.html; (새로고침 시 404 방지)

- 비동기 타임아웃: 1,800,000ms (30분) (SSE 연결 유지용)
- JPA 정책: ddl-auto: update (개발 단계), show-sql: true
