# 📌 외부 서비스 활용 명세서

## 1. 개요

본 프로젝트는 장소 추천 및 사용자 인증 기능 구현을 위해 다양한 외부 API 및 클라우드 서비스를 활용하였습니다.  
각 서비스의 용도, 인증 방식, 환경 변수, 제한 사항을 아래와 같이 정리하겠습니다.

---

## 2. 외부 서비스 목록

---

### 2.1 지도 및 장소 검색 API

#### 📍 Kakao Map API

- **용도**
  - 키워드 기반 장소 검색
  - 지도 시각화 (Frontend)
- **사용 API**
  - Local REST API
  - JavaScript SDK
- **인증 방식**
  - REST API Key
  - JavaScript Key

- **환경 변수**
  KAKAO_REST_API_KEY=your_kakao_rest_api_key  
  KAKAO_JS_API_KEY=your_kakao_js_api_key

- **요청 예시**
  GET https://dapi.kakao.com/v2/local/search/keyword.json?query=삼겹살  
  Authorization: KakaoAK {REST_API_KEY}

- **특징 및 제한사항**
  - 일부 상세 정보 부족

---

#### 📍 Naver Map API

- **용도**
  - 지도 렌더링
- **인증 방식**
  - Client ID / Secret

- **환경 변수**
  NAVER_CLIENT_ID=your_naver_client_id  
  NAVER_CLIENT_SECRET=your_naver_client_secret

---

#### 📍 Google Maps API

- **용도**
  - 상세 정보 보완
- **환경 변수**
  GOOGLE_MAPS_API_KEY=your_google_maps_api_key

---

### 2.2 사용자 인증

#### 📍 Google OAuth 2.0

- **환경 변수**
  GOOGLE_CLIENT_ID=your_google_client_id  
  GOOGLE_CLIENT_SECRET=your_google_client_secret  
  GOOGLE_REDIRECT_URI=http://localhost:3000/login/oauth2/code/google

---

### 2.3 서버 및 배포 환경

#### 📍 AWS EC2

OS: Ubuntu 22.04  
Java: 21

#### 📍 Nginx

- Reverse Proxy 및 정적 파일 제공

---

## 3. 환경 변수 통합 정리

| 변수명             | 설명               |
| ------------------ | ------------------ |
| KAKAO_REST_API_KEY | 카카오 REST API 키 |
| NAVER_CLIENT_ID    | 네이버 API ID      |
| GOOGLE_CLIENT_ID   | 구글 로그인 ID     |
| JWT_SECRET         | JWT 키             |

---

## 4. 구조

[Client] → [Frontend] → [Nginx] → [Backend] → External APIs

---

## 5. 이슈

- Kakao API 500 오류 → Authorization 헤더 수정
- Google 로그인 오류 → redirect URI 수정

---

## 6. 결론

멀티 API 전략을 통해 데이터 품질을 향상시켰습니다.
