# 시연 시나리오

---

## 1. 메인 페이지 진입
- **액션**: 브라우저에서 서비스 URL 접속
- **화면 설명**
  - **전체화면**: 서비스의 핵심 가치를 담은 소개 배너 노출
  - **하단**: 주요 기능 및 기대 효과 요약 섹션
- **시연 포인트**
  > "우리 서비스는 사용자가 겪는 [기존 문제점]을 해결하고, [핵심 가치]를 제공하기 위해 기획되었습니다."

---

## 2. 회원가입 및 로그인
- **액션**: 중앙 하단 **`[구글 / 네이버 로그인]`** 버튼 클릭
- **로그인 페이지 이동 및 인증**
  - 이메일 / 비밀번호 입력 후 **`[로그인]`** 버튼 클릭
- **시연 포인트**
  - OAuth 2.0 기반의 간편 로그인 연동 설명 (보안성 및 편의성 강조)

---

## 3. 메인 대시보드
- **액션**: 로그인 성공 시 대시보드 자동 이동
- **화면 구성**
  - **좌측 (사이드바)**: 홈(추천 챗봇), 검색, 마이플랜, 환경설정, 마이페이지
  - **중앙**: 카카오 지도 API 기반의 실시간 위치 정보
  - **상단**: 사용자 요청에 따른 인터랙티브 피드백 영역
- **시연 포인트**
  > "통합 대시보드를 통해 복잡한 이동 없이 한 화면에서 모든 핵심 기능을 직관적으로 이용할 수 있습니다."

---

## 4. 핵심 기능 실행

### 4.1. 홈 – AI 플래너 (추천 챗봇)
- **액션**: 챗봇과 대화 시작
- **주요 기능**
  - 자연어 기반 음식점 추천 시스템 활용
  - 기존 생성 중인 플랜 이어서 생성 및 정보 업데이트
  - AI 분석 결과에 따른 맞춤형 정보 수신
- **특이사항**: 입력된 대화 맥락을 파악하여 플랜 작성 시 필요한 데이터를 자동 완성

### 4.2. 검색 기능
- **액션**: 사이드바 **`[검색]`** 메뉴 클릭 후 키워드 입력
- **상세**: **`[검색]`** 버튼 클릭 시 음식점 데이터 및 지도 마커 조회

### 4.3. 마이플랜 관리
- **액션**: 사이드바 **`[마이플랜]`** 클릭
- **주요 기능**
  - **`[새 플랜 만들기]`**: 제목 및 상세 내용 작성
  - **플랜 상세보기**: 생성된 플랜의 세부 일정 및 동선 확인

---

## 5. 상세 정보 및 관리
- **액션**: 리스트에서 특정 항목 클릭 시 상세 페이지 이동
- **화면 설명**
  - 장소 및 계획의 상세 데이터 표시
  - **`[수정]`** / **`[삭제]`** 버튼을 통한 원격 데이터 관리 시연

---

## 6. 서비스 종료
- **액션**: 좌측 하단 **`[로그아웃]`** 버튼 클릭
- **마무리**: 세션 종료 확인 및 최종 인사
