# MVP 요구사항 정의

> 현재 구현된 페이지/기능 기반 초안입니다. 사용자가 보완해주세요.

---

## 핵심 기능

### 1. 인증 (Auth)
- [ ] Google OAuth 로그인
- [ ] Naver OAuth 로그인
- [ ] 신규 유저 온보딩 (설문: 이용 목적, 연령대, 성별)
- [ ] 토큰 기반 인증 (AccessToken / RefreshToken)

### 2. 지도 (Map)
- [ ] Naver Map 기반 장소 탐색
- [ ] 현재 위치 기반 지도 중심 설정 (Geolocation)
- [ ] 장소 마커 표시
- [ ] 마커 클릭 시 정보창 (InfoWindow)

### 3. 장소 검색 (Place)
- [ ] 키워드 기반 장소 검색
- [ ] 페이지네이션
- [ ] 검색 결과 지도 연동

### 4. 플랜 (Plan)
- [ ] 플랜 생성 (제목, 날짜, 인원, 예산, 유형, 메모, 장소 목록)
- [ ] 내 플랜 목록 조회
- [ ] 플랜 상세 조회
- [ ] 플랜 수정/삭제

### 5. AI 채팅 (Chat)
- [ ] 채팅 세션 생성/관리
- [ ] AI 기반 장소 추천 대화

### 6. 사용자 설정 (Settings)
- [ ] 프로필 수정 (이름, 자기소개)
- [ ] 계정 관리
